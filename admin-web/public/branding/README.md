# SkinCare AI 로고

피부의 부드러운 두 곡선을 S 형태로 연결하고 민트색 분석 포인트를 더한 심벌입니다. 기존 관리자 웹의 남색을 기본색으로 사용했습니다.

## SVG 파일

| 파일 | 용도 |
| --- | --- |
| `skincare-ai-logo.svg` | 심벌과 서비스명이 결합된 기본 로고. 흰색·밝은 배경용 |
| `skincare-ai-logo-inverse.svg` | 어두운 배경용 전체 로고. 흰색 글자와 민트색 AI |
| `skincare-ai-symbol.svg` | 심벌 단독. 앱 아이콘·프로필·파비콘용 |
| `skincare-ai-symbol-inverse.svg` | 남색 배경에서 경계가 구분되는 심벌 |
| `skincare-ai-wordmark.svg` | 서비스명 단독, 밝은 배경용 |
| `skincare-ai-wordmark-inverse.svg` | 서비스명 단독, 어두운 배경용 |

모든 SVG는 투명 배경의 실제 벡터입니다. 비트맵 이미지를 넣지 않았고 글자는 윤곽선으로 변환되어 있어 별도 글꼴 설치나 네트워크 연결이 필요하지 않습니다. Figma·Illustrator·Inkscape 등으로 가져와 색상과 크기를 편집할 수 있습니다.

`skincare-ai-logo-kit.zip`에는 위 SVG 6개와 이 안내 및 글자 윤곽선의 글꼴 라이선스가 들어 있습니다.

## 색상과 사용

- 기본 남색: `#102D6B`
- 민트 포인트: `#35D5BF`
- 밝은 배경의 AI 글자: `#087F8C`
- 어두운 배경용 심벌 바탕: `#204786`
- 흰색: `#FFFFFF`

가로세로 비율을 유지하고 심벌 폭의 1/4 이상 여백을 두는 것을 권장합니다. 심벌은 24px 이상, 전체 로고는 가로 160px 이상을 권장합니다. 작은 브라우저 탭에는 심벌 단독을 사용합니다. 역상 로고는 어두운 배경에서 사용하세요.

웹의 사이드바에는 역상 심벌과 워드마크를 조합해 적용했고, 사이드바를 접으면 심벌만 표시합니다. `public/favicon.svg`는 기본 심벌과 동일한 벡터입니다.

글자 윤곽선은 DejaVu Sans Bold를 바탕으로 만들었으며 관련 고지는 `FONT-LICENSE.txt`에 동봉했습니다.
