# Gachon SkinCare AI · Admin Web

> 공개 서버의 실제 관리자 화면은 `operational/`이며 백엔드 빌드 시 `/admin/`에 포함됩니다.
> 아래 React 실행 방법은 디자인 미리보기용입니다. 실제 문의·기관·AI 상태·검수 관리는
> 공개 서버의 `/admin/`을 사용하세요. 모듈별 구조는 `operational/README.md`를 참고하세요.
> React도 `constants/navigation.ts`, `hooks/usePreviewStore.ts`, `layouts/Sidebar.tsx`,
> `components/GlobalSearch.tsx`로 라우팅·저장소·사이드바·전체 검색을 분리했습니다.

공유된 관리자 웹 와이어프레임을 기준으로 만든 한국어 React + TypeScript + Vite 프로젝트입니다. 남색 사이드바, 흰색 카드, 위험도 배지와 6개 관리 화면으로 구성했습니다.

## 내 컴퓨터에서 실행하기

Node.js **22.12 이상**이 필요하며 **Node.js 24 LTS**를 권장합니다. `package.json`이 있는 프로젝트 폴더에서 실행하세요.

```bash
git pull origin main
npm ci
npm run dev
```

컴퓨터의 브라우저에서 `http://localhost:5173`을 여세요. 개발 서버를 실행한 터미널은 그대로 두면 됩니다. 종료는 `Ctrl + C`입니다. 소스를 수정하거나 최신 코드를 가져오면 개발 서버가 변경 내용을 반영합니다.

설치한 저장소 안에 `Admin-web` 폴더가 한 번 더 있다면, 안쪽의 `package.json`이 있는 폴더에서 실행해야 합니다. 환경 변수나 API 키는 필요하지 않습니다.

## 샘플 데이터와 실제 연동 범위

화면 기준일은 **와이어프레임과 동일한 2026-09-29**입니다. 현재 날짜나 실제 운영 통계가 아닙니다.

- 상단 지표의 12,847명·438건·1,284개 기관 등은 와이어프레임의 **예시 전체 지표**입니다.
- 표에는 **대표 샘플 사용자 15명, 진단 18건, 의료기관 12개, 문의 4건**이 있으며 하단 페이지 수는 실제 로드된 샘플 기준입니다.
- 사용자 상태, 진단 처리 상태, 문의 답변은 현재 브라우저의 `localStorage` 키 `gachon-skincare-admin-wireframe-v2`에 저장됩니다. 브라우저·기기 간 동기화되지 않습니다.
- 초기 초록색 데모의 `gachon-skincare-admin-v1` 데이터는 삭제하지 않습니다. 새로운 와이어프레임 버전은 별도 저장소 키를 사용합니다.
- 새 버전의 샘플을 초기화하려면 해당 사이트의 위 `v2` 저장소 항목을 삭제한 뒤 새로고침하세요.

**관리자 인증·백엔드·데이터베이스·실제 AI 분석·의료기관 API·이메일 발송은 연결되지 않았습니다.** 문의 답변 저장은 실제 사용자에게 메시지를 보내지 않습니다. 의료기관 동기화 버튼은 연동 안내를 표시하며 외부 API를 호출하지 않습니다. 기관명·진단·성능 수치는 가상 정보이므로 실제 진료나 운영에 사용하지 마세요.

실서비스 연결 시 관리자 로그인과 서버 권한 검증, API·DB, 실제 모델 및 모니터링, 의료기관 데이터와 문의 발송 기능을 구현해야 합니다. 비밀키는 프론트엔드에 넣지 않고 서버에서 관리하세요.

## 검증

```bash
npm test            # 데이터·필터·저장·CSV 단위 테스트 13개
npm run typecheck   # TypeScript 검사
npm run build       # 타입 검사와 프로덕션 빌드
npm run preview     # 빌드 화면 확인, 4173 포트
npm run test:e2e    # 브라우저 기능 테스트 11개
```

브라우저 테스트는 `CHROMIUM_PATH`에 지정한 브라우저, Linux의 `/usr/bin/chromium`, Playwright가 설치한 Chromium 순서로 사용합니다. **Windows에서 브라우저 테스트를 처음 실행한다면** 다음 명령으로 테스트용 Chromium을 먼저 설치하세요. 일반 개발 서버 실행에는 필요하지 않습니다.

```bash
npx playwright install chromium
npm run test:e2e
```

브라우저 테스트는 6개 화면 이동, 위험도 필터, 진단 상태 유지, 사용자 상태 변경, 의료기관 검색, 문의 답변 저장·수정, 전체 검색·알림, CSV, 페이지 이동과 모바일 너비를 검증합니다.

## 클라우드 환경

기존 `/workspace/Admin-web` 체크아웃을 사용합니다. 클라우드 작업은 이미 격리되어 있으므로 별도 Git worktree를 만들 필요가 없습니다.

`.npmrc`는 npm 캐시를 무시된 `.npm-cache/`에 저장합니다. 설치 중 TLS·패키지 무결성 검증을 유지합니다. `node_modules`, `dist`, `.env`, 테스트 산출물은 Git에서 제외됩니다.
