문의 관리

기관 정보

등록된 정보이며 실시간 진료 가능 여부가 아닙니다. 확인한 출처와 날짜를 함께 기록하세요.

기관 등록

숨김으로 저장하면 사용자 검색 목록에서 제외됩니다.

분석 처리 현황

현재 보관 중인 분석 세션의 처리 상태입니다. 완료 건수는 정확도나 위험 판정의 타당성을 뜻하지 않습니다. 삭제된 기록은 집계에서 제외됩니다.

서비스 연결 준비 상태

서버 설정과 계정 존재 여부만 검사합니다. 키가 설정되어 있어도 실제 제공자 연결·문서 승인·전문가 검수가 완료된 것은 아닙니다. 키 값과 담당자 ID는 표시하지 않습니다.

AI 서버 연결

조회 시점의 서버 상태입니다. 모델명은 AI 서버의 등록 정보이며 파일 실측이나 성능평가 결과가 아닙니다.

분석 기록 목록

운영 확인용 기록 번호와 처리 상태만 표시합니다. 사진·문진·통증·메모와 사용자 정보는 포함하지 않습니다.

관리자 감사 이력

초기·추가 관리자 생성과 성공한 관리자 로그인·로그아웃·비밀번호 변경, 기관 변경, 문의 상세 열람·답변, 검수 작업을 기록합니다. 사진·답변 본문·비밀번호·토큰은 감사 이력에 포함하지 않습니다. 이 화면에서 수정하거나 삭제할 수 없습니다.

자료 검수

자료를 고정된 버전으로 보관하고 검수 근거를 기록합니다. 승인해도 서비스 문항·규칙·가이드·모델은 자동 변경되지 않습니다. 작성자는 자기 자료를 검수할 수 없으며, 임상 자료 승인은 별도로 지정한 검수 담당자만 가능합니다.

새 검수 버전

개인정보·환자 사진·개별 문진 내용을 입력하지 마세요. 저장 후 원문은 수정할 수 없으며, 수정 내용은 새 버전으로 등록합니다.
