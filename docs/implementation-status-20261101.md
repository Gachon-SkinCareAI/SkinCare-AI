# SkinCare AI 서비스 구현 상태

2026-11-01. 사용자 앱과 관리자 웹의 서비스 보완 사항이다. 이전 문서의 미구현 표 중 아래 항목은 이 문서로 갱신한다.

| 범위 | 구현한 기능 | 실제 운영 전 남은 조건 |
|---|---|---|
| 의료기관 | 공공 병·의원/약국 API 어댑터, 지역·기관명 검색, 페이지, 출처·조회시각, 오류 상태, 선택적 위치·거리, 등록 기관 검색 병행 | 공공데이터 서비스 활용신청/키 설정과 실제 응답 검증. 전체 주변 기관 거리순·실시간 진료 가능 여부는 제공하지 않음 |
| 동의 | 건강정보 별도 필수 동의, 과거 계정 재동의, 목적별 변경 이력, 학습 선택 동의·철회 | 승인된 약관·개인정보·선택 학습 목적 문서. 학습 반출 기능은 꺼짐 |
| 탈퇴 | 본인 확인 문구, 관련 서비스 DB 기록·사진·계정 트랜잭션 삭제, 토큰 차단, 복원 시 삭제 목록 재적용 | 운영 보관기간·예외, 외부 저장소·제공자 연결 해제, 원본 DB 손실 시 재해 복구 절차 검토 |
| 관리자 | 성공한 운영 행위 감사, 고정 원문 검수, SHA-256, 이전 버전 연결, 요청·반려·승인 권한/근거/동시성 검사 | 실제 검수 담당자 지정과 콘텐츠 검수. 승인 결과는 서비스에 자동 반영하지 않음 |
| DB | V004 추가 마이그레이션, 적용 전 백업, 기존 값 보존, 독립 QA DB에서 서비스/복원 검증 | 운영 배포·별도 보관정책 |

Google/Kakao/Naver 실제 계정 인증과 Android USB 테스트는 기존 보류 상태다. 공공 API 키도 아직 없다. 모의 외부 제공자와 합성 소프트웨어 시험 이미지는 독립 QA DB에서만 사용한다. 의료기관 실자료나 새 임상 성능 결과로 취급하지 않는다.

실행·시험 결과는 작업 폴더의 `outputs/service-completion-v1`을 참고한다. [추가 API와 데이터 처리](api/service-completion.md), [로컬 MySQL 실행](../deploy/mysql/README.md), [소셜 인증](social-auth.md)에서 상세 설정을 확인한다.

AI 모델·데이터셋·라벨은 이번 서비스 작업에서 변경하지 않았다. 탐색 재학습 후보는 기본 모델로 승격하지 않았다. 실제 성능 재평가, 출처 확인, 전문가 검수는 별도 AI 작업이다.


후속 구현: 필수 정책 문서의 서버 검증, 서버 정책 버전에 맞춘 앱 동의, 관리자 설정 준비 상태, 비밀값을 숨기는 읽기 전용 로컬 점검 도구를 추가했다. [정책·준비 상태 명세](api/service-readiness.md)와 `outputs/service-readiness-v1` 결과를 참고한다. 실제 키/승인 문서는 여전히 필요하며, 코드에서 승인이나 실제 제공자 검증을 완료했다고 표시하지 않는다.
