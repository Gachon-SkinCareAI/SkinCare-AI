# 모델 자원

이 폴더는 ONNX 전용 저장소가 아니다. 현재 서비스의 탐지·분류 모델은 기존 외부 PyTorch 가중치 경로 또는 배포 시 검증·복사한 동일 가중치 저장소에서 로드한다.

- `AI_DETECT_PATH`: 탐지 모델
- `AI_CLASSIFY_PATH`: 분류 모델
- `AI_ENERGY_PATH`: 검증한 에너지 기준 파일

기본 모델을 임의로 이동·덮어쓰지 않는다. 새 후보를 만들 때는 버전별 파일과 학습 설정·분할 목록·평가 보고서를 함께 보관하고, 검증 전에는 기존 서비스 경로를 변경하지 않는다. 변환 스크립트가 있어도 ONNX 파일 생성이나 출력 일치 검증이 끝난 것은 아니다. 모델 파일과 데이터셋은 이번 소스 폴더 정리에서 변경하지 않았다.
