# SkinCare AI — React Native 화면 구현

기존 인증 없는 로그인·회원가입·홈에 촬영, 사진 선택, 신규 상처 등록, 기록 목록·상세, 공통 하단 탭을 연결한 Expo 프로젝트입니다.

## 실행

```sh
npm ci
npx expo start
```

웹: `npm run web`. 기기: SDK 58과 호환되는 Expo Go 또는 개발 빌드로 실행합니다. 카메라는 실제 기기에서 확인해주세요. 웹 카메라는 HTTPS 또는 localhost, 브라우저 권한과 카메라 장치가 필요합니다.

## 구현된 흐름

- 로그인·회원가입·Google 버튼 → 인증 없이 홈 진입
- 홈 최근 분석 / 회복 경과 → 선택한 상처 상세
- 상처 분석 시작 → 카메라 / 갤러리 → 사진 확인 → 촬영 날짜 입력 → 임시 분석 대기 기록
- 카메라 접근 요청, 권한 거절 안내, 플래시, 확대, 전후면 전환, 사진 촬영
- 시스템 사진 선택기, JPG/PNG/HEIC·HEIF 및 10MB 제한 검사, 미리보기·재선택
- 기록 목록: 전체·진행 중·회복 완료 필터, 새 상처 추가, 기존 상처 경과 사진 추가
- 경과 상세: 사진 비교, 예시 면적 그래프, 촬영 내역, 추가한 사진 표시
- 공통 Safe Area, 헤더, 하단 탭, Android 뒤로가기
- 백과·병원 탭은 이번 요청 범위 밖이므로 준비 중 화면, 마이 탭은 시연 세션 종료 제공

## 서버 연결 전 동작

API, 실제 계정 생성, OAuth, AI 추론, 서버 사진 업로드는 실행하지 않습니다. 등록 사진과 기록은 React 상태에만 보관되어 새로고침·앱 재시작·로그아웃 시 사라집니다. 촬영한 사진을 기기 갤러리에 자동 저장하지 않습니다. 실제 의료 분석 결과를 생성하지 않으며, 새 기록은 `분석 대기`로 표시합니다.

기존 데이터는 피그마 예시입니다. 홈과 기록 데이터가 일부 달랐던 원본은 선택한 부위·날짜·사진이 같은 기록을 가리키도록 맞췄습니다. 팔 상세 그래프는 원본의 6개 수치를 사용합니다. 없는 촬영 사진은 예시 이미지를 반복 사용합니다. 기간 선택은 마지막 예시 촬영일 기준이며 예시 기록이 모두 한 달 안에 있어 모든 기간에 동일하게 표시됩니다. 갤러리의 원본 예시 사진 격자는 실제 사용자 사진처럼 보이지 않도록 선택한 사진과 빈 상태로 대체했습니다.

남색·회색 색상, Noto Sans KR, 카드·버튼·탭 구성과 화면 흐름을 반영했습니다. 기기 테두리와 가짜 상태바는 제외하고 OS Safe Area를 사용합니다. 기존 홈·인증 SVG와 이미지 원본을 재사용합니다.

## 파일 구조

- `App.js`: 폰트·리소스 로딩, 인증 없는 진입
- `src/AppShell.js`: 화면 스택, 탭 이동, 임시 기록·사진 상태
- `src/components/Common.js`: 헤더·레이아웃·하단 탭·카드·버튼
- `src/screens/HomeScreen.js`: 홈 최근 분석·회복 경과
- `src/screens/CaptureScreen.js`: 카메라·갤러리
- `src/screens/RecordScreens.js`: 목록·상세·신규 입력
- `src/data/homeDemo.js`: 홈 예시 데이터
- `src/utils/draft.js`: 사진·날짜 검증

## 확인

```sh
node --test tests/draft.test.mjs
npx expo export --platform all
```

웹에서 인증 없이 진입, 이미지 선택, 잘못된 날짜 차단, 임시 등록·상세 표시, 기록 필터, 탭 이동, 로그아웃을 자동 확인했습니다. 실제 기기 카메라 촬영·운영체제 권한 창·HEIC 렌더링은 기기에서 추가 확인해야 합니다. 네이티브 권한 설정은 `app.json`에 포함했습니다.
