구분항목·목적 및 보관 상한
소셜 계정로그인 제공자, 제공자 식별정보의 해시, 서비스 계정 ID, 닉네임, 제공된 이메일·프로필 이미지 URL, 생성·접속 시각. 인증과 계정 관리에 사용합니다. 계정 생성일부터 최대 5년, 탈퇴 시 조기 삭제합니다. 최초 인증 시 건강정보 동의 전에도 계정이 생성될 수 있습니다.
분석·경과사진, 문진 응답, 분석 결과, 통증, 경과 메모, 날짜별 사진과 생성 시각. 요청한 분석 및 기록 조회·비교에 사용합니다. 각 수집일부터 최대 5년이며 해당 기록 삭제·탈퇴·연결 계정 만료 시 먼저 삭제합니다.
문의·답변제목, 내용, 답변, 작성 시각과 관련 기록 ID. 문의 응대에 사용하며 관리자가 열람할 수 있습니다. 수집일부터 최대 5년, 탈퇴 시 조기 삭제합니다. 별도 삭제 요청은 담당자에게 접수할 수 있습니다.
동의·설정목적별 동의 여부·문서 버전·시각, 사용자 설정, 인증 상태 관리 정보. 선택 상태와 접근을 관리합니다. 수집일부터 최대 5년 또는 계정 삭제 시까지 보관하며 만료된 일회용 인증 정보는 더 일찍 제거합니다.
감사·삭제 목록관리자 행위의 식별자·시각·처리 내용, 삭제한 계정·기록의 무작위 서비스 식별자와 삭제 시각. 운영 점검과 과거 자료의 복원 방지에 사용합니다. 사진·문진·이메일을 삭제 목록에 복사하지 않으며 발생일부터 최대 5년 보관합니다.

항목: 상처 사진, 문진 응답, 분석 결과, 통증·경과 메모와 날짜별 사진.
목적: 사용자가 요청한 사진 분석·문진·결과 제공 및 상처 경과 기록·조회.
보관: 수집일부터 최대 5년. 해당 기록 삭제·탈퇴 요청 또는 연결 계정 만료 시 조기 삭제하며 관리 백업에도 삭제를 반영합니다.

일반 이용 조건과 별도로 건강정보 처리에 직접 동의해야 합니다. 거절할 수 있으나 거절하면 건강정보 분석·기록 기능은 사용할 수 없습니다. 앱의 탈퇴 또는 담당자 문의로 철회할 수 있으며 동의 전에도 탈퇴할 수 있습니다.

4. 보관기간과 파기 방법

5년은 운영자가 정한 최대 보관기간이며 일률적인 법정 보존 의무를 뜻하지 않습니다. 처리 목적 달성·보관기간 만료·삭제 요청 등으로 더 이상 필요하지 않으면 삭제합니다. 수집일 기준을 사용하며 이후 접속·수정으로 기존 정보의 보관기간을 연장하지 않습니다.

현재 구성은 사진을 포함한 서비스 자료를 MySQL에 저장합니다. 기록 삭제·탈퇴 시 관련 DB 자료를 트랜잭션으로 삭제합니다. 보관기한 점검은 관리 실행기로 시작할 때와 실행 중 1분 주기로 수행합니다. 정지 중 도래한 기한은 다음 시작 시 서비스를 열기 전에 반영합니다.

관리 실행기가 만든 백업은 삭제·만료 감지 시 삭제를 반영한 새 백업을 먼저 확인한 뒤 이전 백업 파일을 제거합니다. 백업을 이용하기 전 최신 삭제 목록과 만료 기준으로 다시 걸러 삭제된 자료가 서비스에 돌아오지 않게 합니다. 만료 점검 실패 시 서비스 시작·운영을 중단하여 실패 사실을 확인하도록 구성합니다.

이 처리는 프로젝트 관리 도구가 생성한 로컬 DB 백업에 적용됩니다. 운영자가 별도로 복사·내보낸 자료나 OS·클라우드 백업까지 자동으로 탐색하지는 않습니다. 운영자는 별도 사본에도 같은 삭제 기준을 적용해야 하며, 공개 배포 전 실제 저장매체·백업 경로와 파기 방법을 확인해야 합니다. DB 행·파일 삭제는 저장장치 전체의 물리적 완전 소거를 뜻하지 않습니다.

5. 외부 서비스와 기기 정보

소셜 로그인은 Google·Kakao·Naver 인증 화면과 프로필 API를 사용합니다. 제공자 비밀번호는 해당 제공자가 처리하며 SkinCare AI가 수집하지 않습니다. 인증 과정의 제공자 access/refresh token은 장기 저장소에 보관하지 않습니다. 프로필 이미지 표시 시 이미지 제공 서버에 요청이 발생할 수 있습니다.

의료기관 검색 조건(시·도, 시·군·구, 기관명)은 공공 의료기관 API로 전달합니다. 사진·문진을 이 검색 API에 보내지 않습니다. 외부 지도·전화 버튼은 해당 앱이나 서비스로 연결됩니다. 위치 권한을 허용하면 기기 안에서 거리 계산에 사용하며 현재 위치를 SkinCare 서버로 보내지 않습니다.

웹 로그인 중 일회용 검증값은 임시 저장 후 제거하며 웹 로그인 토큰은 메모리에, 네이티브 토큰은 기기 보안 저장소에 보관합니다. OAuth 진행 중 서버 세션 쿠키를 사용합니다. 현재 분석은 프로젝트의 로컬 AI 서버를 사용합니다. 외부 AI·클라우드 도입 시 위탁·국외 이전 여부, 전달 항목과 목적 등을 확인해 필요한 안내·절차를 먼저 마련합니다.

6. 선택적 학습 이용

사용자 사진의 자동 학습 반출은 비활성화되어 있습니다. 학습 동의는 기본값이 미동의이며 별도 목적 안내 문서가 없으면 새 동의를 받지 않습니다. 기존 선택 동의의 철회는 가능하며 필수 서비스 이용과 구분합니다.

7. 권리 행사와 보호 조치

앱에서 본인 기록 조회·삭제, 프로필 변경, 선택 동의 철회와 탈퇴를 할 수 있습니다. 그 밖의 열람·정정·삭제·처리정지 요청은 담당 이메일로 접수합니다. 해당 기능이 실패한 경우에도 담당자에게 요청할 수 있습니다.

사용자 소유권·관리자 역할 검사, 토큰 검증, 비공개 설정, 관리자 감사 이력을 적용합니다. 현재는 로컬 연구·시연 단계이며 공개 배포의 보안·법률 검토 완료를 의미하지 않습니다. 미성년자 대상 공개 제공이나 별도 법정 보존 예외를 현재 설정에 임의로 가정하지 않습니다.

8. 문서 변경과 참고

내용 변경 시 문서 버전과 적용일을 갱신하고 필요한 항목은 앱에서 다시 동의받습니다. 현재 문서는 운영자가 확인한 로컬 처리 범위를 기재한 것으로 법률 검토 완료 표시가 아닙니다.
