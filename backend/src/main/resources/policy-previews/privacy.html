가입 동의에 사용하는 확정 문서가 아닙니다.
운영 주체·문의 연락처·보관 및 파기 기준을 확인하고 내용을 검토해야 합니다. 이 초안을 열어 보아도 가입 동의가 저장되거나 분석 기능이 활성화되지 않습니다.
이용약관 초안개인정보 처리방침 초안건강정보 처리 안내

1. 운영 주체와 연락처

운영 주체·개인정보 관련 문의 담당자·연락처: 확인 필요

이 초안은 현재 코드의 처리 흐름을 설명합니다. 실제 서비스의 처리 근거, 운영 담당자, 위탁·국외 이전 해당 여부와 보관 기준을 확인하여 확정해야 합니다.

2. 처리하는 정보와 목적

구분항목과 목적
소셜 계정로그인 제공자, 제공자 사용자 식별정보의 해시, 서비스 계정 ID, 닉네임, 제공된 경우 이메일·프로필 이미지 URL, 계정 생성·접속 시각 등. 계정 식별과 로그인 유지에 사용합니다. 최초 인증 시 건강정보 동의 전에도 계정이 만들어질 수 있습니다.
분석·경과상처 사진, 문진 응답, 분석 결과, 생성 시각, 통증·경과 메모와 날짜별 사진. 요청한 분석과 기록 조회·비교에 사용합니다.
문의문의 제목·내용·답변·작성 시각. 문의 처리와 답변 조회에 사용하며 관리자가 문의를 확인할 수 있습니다.
동의·설정목적별 동의 여부·문서 버전·시각, 사용자 설정, 인증 토큰의 유효성 관리 정보. 선택 상태와 계정 접근을 관리합니다.
운영 기록탈퇴 계정의 서비스 ID·삭제 시각, 관리자 행위와 처리 시각 등의 감사 이력. 삭제 자료의 복원 방지와 운영 이력 확인에 사용합니다. 각각의 보관기간은 아직 확정되지 않았습니다.

3. 건강정보 처리에 대한 별도 안내

항목: 상처 사진, 문진 응답, 분석 결과, 통증·경과 메모 및 날짜별 사진.
목적: 사용자가 요청한 사진 분석, 문진과 결과 제공, 상처 경과 기록·조회.
현행 서비스 DB: 기록 삭제 또는 탈퇴 시 해당 자료를 삭제하는 기능이 있습니다. 자동 만료기간과 백업·감사·삭제 목록의 보관 및 파기 기준은 확인이 필요합니다.

건강정보 처리 동의는 일반 이용약관·개인정보 확인과 별도 항목으로 받습니다. 거절할 수 있으며, 거절하면 건강정보 분석·기록 기능을 이용할 수 없습니다. 동의 전에도 탈퇴할 수 있습니다. 이 초안 자체는 동의서로 사용되지 않습니다.

4. 보관·삭제와 백업

현재 로컬 구성은 계정과 사진·문진·경과 등을 MySQL에 저장합니다. 사용자가 기록을 삭제하거나 탈퇴하면 현행 서비스 DB에서 해당 자료를 제거합니다. 소셜 인증 중 받은 제공자 access/refresh token은 서버의 장기 저장소에 보관하지 않도록 구현되어 있습니다.

백업 파일은 별도로 남아 있을 수 있고 즉시 파기되지 않습니다. 개발용 복원 도구는 최신 삭제 목록을 적용한 후 복원된 DB를 사용하도록 구성되어 있습니다. 운영 백업, 감사 이력, 삭제 목록, 서버 로그의 최종 보관기간·자동 파기 일정·관리 담당자는 확정 전입니다.

자료 종류별 보관기간, 삭제 예외와 근거, 백업 파기 방법 및 주기는 운영자가 확정해야 합니다. 임의의 기간이나 법정 보존 의무를 가정하지 않았습니다.

5. 외부 서비스와 기기 정보

소셜 로그인은 Google·Kakao·Naver 인증 화면과 프로필 API를 사용합니다. 제공자에게 입력하는 비밀번호는 해당 제공자가 처리합니다. 프로필 이미지 URL을 열면 해당 이미지 제공 서버에 요청이 발생할 수 있습니다.

의료기관 검색은 시·도, 시·군·구, 기관명 같은 검색 조건을 공공 의료기관 API로 전달합니다. 상처 사진이나 문진을 이 검색 API에 보내는 기능은 없습니다. 외부 지도·전화 버튼을 선택하면 해당 앱 또는 서비스가 열리며 해당 서비스의 처리방침이 적용됩니다.

현재 위치는 권한을 허용한 경우 기기에서 기관과의 거리 계산에 사용하며 SkinCare 서버에 보내지 않습니다. 웹 로그인에서는 이동 중 일회용 검증값을 임시 저장소에 두고 처리 후 제거하며, 웹 로그인 토큰은 메모리, 네이티브 토큰은 기기의 보안 저장소에 보관하도록 구현되어 있습니다. OAuth 진행 중에는 서버 세션 쿠키를 사용합니다.

현재 검증된 로컬 분석 구성은 프로젝트의 AI 서버와 기존 모델을 사용합니다. 외부 AI·클라우드 서비스 또는 선택형 LLM을 활성화하는 경우 실제 데이터 전달 범위·수탁자·국외 이전 여부를 별도로 확인해 문서에 반영해야 합니다.

6. 선택적 학습 이용

사용자 사진의 자동 학습 반출 기능은 비활성화되어 있습니다. 선택적 학습 동의는 기본값이 미동의이며, 별도 목적 안내 문서가 없으면 새 동의를 받을 수 없습니다. 이미 동의한 선택 항목의 철회는 가능합니다. 향후 학습 이용을 도입하면 대상 자료·목적·기간·철회 처리 기준을 먼저 확정해야 합니다.

7. 권리 행사와 보호 조치

앱에서 본인 기록 조회·삭제, 프로필 변경, 선택 동의 철회와 탈퇴 기능을 제공합니다. 그 밖의 열람·정정·처리정지 등 요청을 받을 담당자와 연락처, 본인 확인 및 응답 절차는 운영 정보와 함께 확정해야 합니다. 미성년자 이용 대상과 필요한 확인 절차도 아직 정하지 않았습니다.

현재 코드는 사용자 소유권과 관리자 역할 검사, 토큰 검증, 비공개 설정 파일, 관리자 감사 이력 등의 보호 기능을 포함합니다. 실제 배포 서버·DB·백업의 접근 권한, 암호화·로그 정책과 점검 절차가 모두 검증되었다는 뜻은 아닙니다.
